## Presunciones clave → [[Presunciones en las Relaciones de Poder]]

| Presunción | Regla |
|---|---|
| Dominio | Se presume perfecto salvo prueba en contrario |
| Cosas sobre cosa ajena | Se presumen libres de gravamen |
| Poseedor vs. servidor | Se presume poseedor quien ejerce poder de hecho |
| Legitimidad de la relación de poder | Se presume legítima |
| Buena fe | Se presume, salvo los 3 casos taxativos del art. 1919 |
| Onerosidad (usufructo, servidumbre) | Se presume onerosa en caso de duda |
| Servidumbre real o personal | En caso de duda, se presume **personal** |
| Fecha y extensión de la posesión | Se presume desde la fecha del título, con su extensión |
| Continuidad de la posesión | Se presume continua entre dos momentos probados |
| Construcciones/siembras/plantaciones | Se presumen hechas por el dueño del inmueble |
| Ganado marcado a nombre de otro | Presunción de mala fe del adquirente |

## Fórmulas de adquisición y transmisión → [[Adquisicion Transmision y Extincion de Derechos Reales]]

| Fórmula | Contenido |
|---|---|
| Adquisición derivada entre vivos | **Título suficiente + modo suficiente** (art. 1892) |
| Modo suficiente (regla) | Tradición posesoria |
| Modo suficiente (registrable con inscripción constitutiva) | Inscripción registral |
| Modo suficiente (servidumbre positiva) | Primer uso ("cuasi-tradición") |
| Posesión vale título (muebles) | Mueble no registrable + no hurtado/perdido + buena fe + oneroso (art. 1895) |
| Justo título | Título con aptitud traslativa, pero otorgante sin capacidad/legitimación plena |
| Boleto de compraventa | **NO** es título suficiente ni justo título |

## Clasificación rápida de garantías → [[Disposiciones Comunes a los Derechos Reales de Garantia]]
